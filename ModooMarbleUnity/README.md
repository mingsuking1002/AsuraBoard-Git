# 아수라판 — 작업명

0.19.1에서는 플레이어 카드에 체력을 표시합니다. 증강·아이템에 연결할 체력 피해 규칙과, 체력 0에서 무인도 이동 및 탈출 후 회복을 지원합니다. [체력 효과 연결과 검증](Documentation/wiki/maintenance.md#체력-효과-연결)

개발을 이어받을 때는 [프로젝트 작업 규칙](AGENTS.md)과 [현재 인수인계](HANDOFF.md)를 읽고 [공통 하네스](../GameHarness/README.md)로 검증합니다.

Unity 6000.3.9f1으로 만든 거래와 빚, 반전이 있는 파티 보드게임입니다. 원본 게임에서 추출한 그래픽·캐릭터·주사위 모델·UI 스킨·폰트를 제거하고 직접 만든 비주얼로 교체했습니다. Synty POLYGON Starter Pack의 바닥판과 Sidekick Starter Pack의 모듈형 캐릭터를 사용합니다. 기본 규칙 엔진과 Steam 멀티는 유지합니다.

## 특수능력 기능 팩 30종 (소스)

제공된 효과 30종을 명시 호출형 독립 규칙 팩으로 구현했습니다. 증강/UI/기존 경기에는 자동 연결하지 않았습니다. 현금·건물·지연 환급·경매 예치/정산까지 처리하며 기본 수치는 조절할 수 있습니다. 신규 43개 포함 총 200개 검사와 전체 C# 컴파일 통과. [기능별 API·기본값·연결 범위](Documentation/special-mechanics.md). 최신 빌드에 이 소스가 포함되어 있습니다.

## 플레이 루프 (0.9.0 소스)

실행 → 메인 메뉴(캐릭터 커스터마이징·환경설정·방 만들기·방 찾기·나가기) → 대기 로비 → 게임 → 경기 결과 → 같은 방 로비 → 재시작으로 연결합니다. 방을 만드는 것만으로 경기는 시작하지 않습니다. 로비에서 맵·증강 횟수를 설정하고 친구 초대·준비·시작을 진행합니다. 0.9.0의 첫 파산 종료는 새 신체 경제 모드에서 만기 미상환 탈락·최후 생존자 승리로 변경했습니다. 경기 결과의 등수만 표시합니다. [플레이 루프 사용법과 검증](Documentation/play-loop.md).

**현재 이 변경은 소스와 컴파일·자동 검사까지 완료했습니다. `Builds/Windows` 실행 파일은 이전 0.8.0입니다. 새 Windows 빌드는 제한된 실행 환경의 Unity 라이선스 연결 실패로 아직 생성하지 못했습니다.**

## 땅 구매와 건설

도시에 도착하면 땅·별장·빌딩·호텔을 나란히 고르는 구매창이 뜹니다. 첫 바퀴에는 별장까지, 출발지를 한 번 통과하면 빌딩, 두 번 통과하면 호텔이 열립니다. 이미 지은 종류는 중복으로 지을 수 없습니다. 선택한 건물만 합산해 결제하고, 세 건물을 모두 보유한 다음 방문에 랜드마크를 건설합니다. [구매 UI·규칙·검증](Documentation/construction.md).

## 증강 선택 구조

모든 플레이어가 자기 화면에서 동시에 3장 중 하나를 고르고, 전원 확정하면 게임을 재개합니다. 클릭 또는 1/2/3으로 선택하고 **선택 확정 / Enter**로 확정합니다. 기본은 1·6·11·16라운드의 4회이며 호스트가 대기실에서 1~8회를 설정할 수 있습니다. 일반·특수 획득을 합친 보유 한도는 8개입니다.

플레이어 카드 바로 위에는 획득한 증강 아이콘만 표시하고, 마우스를 올리면 상세 정보가 뜹니다. 각 플레이어는 매 선택 단계마다 **카드 3장 각각 1회 리롤**할 수 있습니다. 황금 리롤은 한 카드만 한 등급 올리며 페이즈당 1회 사용합니다. 브론즈(구릿빛)·실버(은빛)·골드(금빛)·프리즘(여러 색 테두리)의 등급 색상을 사용합니다. 증강 내용은 전부 비어 있으며, 아이콘은 공통 보석 자리표시자를 사용합니다. 선택·등급·리롤 사용을 기록합니다. 저장·AI·Steam 동기화와 특수 획득 연결부를 포함합니다. [구조와 검증](Documentation/augments.md).

## 직접 만든 비주얼

- 정사각형 32칸 보드와 검은 손그림 테두리, 겹친 종이 카드 UI, 선명한 등급·플레이어·도시 색상
- 캐릭터는 Synty Sidekick 모듈형 모델을 사용. 자체 제작 탐험 로봇은 모델을 로드할 수 없을 때의 대체 표시로 유지
- 모서리가 둥근 주사위 메시와 1~6 눈 도형, 굴림 애니메이션
- 다운로드한 Simple Town 건물 모델과 직접 만든 부품을 조합한 건설 1~4단계 미니어처, 출발·여행·무인도·올림픽·포춘카드 그림
- 플레이어 카드, 버튼, 팝업, 선택 테두리, 말 이동·점프
- 버튼·발걸음·주사위 충돌음은 직접 합성. 한글 글꼴은 Windows 설치 글꼴(맑은 고딕)을 런타임에 사용하며 별도 폰트 파일을 포함하지 않음

카드 바탕색은 증강 등급별로 구릿빛·은빛·금빛·무지개이며, 구매 항목은 땅(갈색)·별장(초록)·빌딩(파랑)·호텔(보라)로 구분합니다. 잠긴 건물은 회색으로 표시합니다. [카드 UI 기록](Documentation/card-ui.md).

자산별 제작 방식과 제거 내역은 [비주얼 제작 기록](Documentation/original-art.md)에 있습니다. 화면의 작업명은 아수라판이며 기존 저장 경로와 실행 파일 이름은 호환을 위해 유지했습니다.

## 플레이

새 로컬 방은 사람 1명과 정원에 맞춘 AI로 구성합니다(총 2~4명). Steam 방에서는 참가자가 각자 조작합니다.

주사위 2개, 더블·연속 세 더블, 이동, 월급, 도시·관광지 구매, 건설, 통행료, 인수, 컬러 효과, 독점 승리, 무인도, 세계여행, 올림픽, 원격 건설, 보너스게임, 카드, 매각·대출·파산, 턴 제한 자산 판정, AI, 저장·불러오기를 포함합니다. 캐릭터 능력치·아이템·특수능력은 적용하지 않습니다.

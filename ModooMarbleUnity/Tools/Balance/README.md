# 아수라판 증강 밸런스 시뮬레이터

Unity 보드게임의 C# 규칙을 직접 실행하는 4인 자동 경기 도구다. 자유 선택 200판과 같은 시드·맵·좌석·선호로 비교하는 120판을 기본으로 생성한다. 실험용 카드 다섯 개는 절약 계약, 정기 수입, 위험 투자, 견제 사격, 보호막이다.

게임 폴더에서 Python 3.10 이상으로 실행한다. Unity 6000.3.9f1의 Editor 설치 경로가 다르면 `--unity`로 지정한다. Editor 창을 실행할 필요는 없다.

~~~powershell
python Tools/Balance/run.py --games 200 --seed 4200
python Tools/Balance/run.py --seed 4200 --replay 0 0 0 -2 --out Validation/BalanceReplay
~~~

기본 결과는 Validation/Balance의 dashboard.html과 matches.jsonl이다. 재현 인자는 시드와 함께 맵, 노이즈, 좌석 회전, 강제 지급 카드 번호를 받는다. 지급 값 -2는 자유 선택, -1은 효과 없는 기준 슬롯, 0~4는 위에 나열한 증강 순서다. 체크를 하네스로 실행하려면 게임 폴더에서 `python ../GameHarness/run.py check balance`를 사용한다.

## 실험 및 지표

- 표준 게임 엔진이 이동, 통행료, 체력, 무인도, 파산, 순위를 처리한다. 실험 모드는 별도 카드 카탈로그와 AI 성향을 사용한다. 카드 중복 선택은 등급이 더 높을 때만 기존 효과를 강화한다.
- 공격·방어·금전·도박·시너지 성향과 세 가지 선택 노이즈를 사용한다. 좌석 배치를 순환하며 주사위·돌발 카드의 난수와 AI 선택·투자의 난수를 분리한다. 골드 리롤 결과는 게임 엔진의 등급 규칙을 따른다.
- 경기 로그의 choices에는 제시, 리롤, 선택 점수와 선택 결과가 들어 있다. events에는 금전 변화, 피해·방어·초과 피해, 무인도 이송이 들어 있다. 통행료 절감은 지불자 절약과 소유자 감소로 보존된다. 보유 좌석당 평균은 미발동을 포함한다.
- 정기 수입과 위험 투자는 발동당 기대 G를 기록한다. 절약·피해·방어는 실제 발동 결과를 집계한다. 자유 선택 승률과 강제 지급 승률 차이는 각각 표시하며, 비교 실험은 첫 드래프트의 지급 선택을 비교한다. 이후 드래프트와 플레이는 각 경기 결과에 따라 진행된다.
- 대시보드의 20배속 버튼은 턴당 50ms로 효과 타임라인을 재생한다. 대량 실행과 시드 재현은 화면 없이 진행한다.

# 양눈 매각 그라데이션 시야 — 0.14.4

## 0.14.5 — 왼눈·오른눈 전이 확대

한쪽 눈의 선명한 영역을 유지하고, 비네트 거리의 전이 범위를 0.45~0.95에서 0.45~1.45로 넓혔다. 어두워지는 구간 폭이 두 배가 되어 이전에 완전히 가려졌던 쪽도 더 넓게 희미하게 보인다. 양눈의 근거리·거리별 시야는 변경하지 않았다.

실제 Windows 플레이어 0.14.5에서 `Validation/unity-single-eye-gradient-verified/runtime-validation.json`은 passed, 런타임 오류 없음. 가려진 방향으로 가까운·중간·먼 세 표본의 정상 대비 밝기는 오른눈 78.35% → 42.48% → 10.33%, 왼눈 78.45% → 42.73% → 10.45%였다. 좌우 각각 희미한 구간 확대와 점진적 밝기 감소를 검사했고 두 캡처를 직접 확인했다. 기존 양눈·이동·완화·복구·HUD 검사도 통과했다. 규칙 검사 290개 통과, Unity 빌드 Succeeded, 경고·오류 0개.

아래는 0.14.4에서 추가한 양눈 그라데이션의 구현과 검증 기록이다.

캐릭터 주변의 선명한 시야는 유지하고 이전의 좁은 원형 경계를 넓은 거리 그라데이션으로 바꿨다. 기본 보드 좌표 기준 반경 66까지 선명하며 거리 600까지 점차 어두워진다. 가장 어두운 지점도 검정 불투명도를 96%로 제한해 먼 보드의 윤곽이 희미하게 남는다. 전체 가우시안 블러는 사용하지 않는다.

양눈 마스크의 거리 비율 `t = Clamp01((거리 - 66) / (600 - 66))`, 불투명도 `0.96 × (1 - (1 - t)^6)`을 사용한다. 반경은 카메라 확대 비율에 맞추고 중심은 실제 화면의 내 말 위치를 따라간다. 원본 겜블과 정확히 같은 밝기라고 주장하지 않으며, 이번 사용자 요청에 맞춘 자체 시야 효과다. 왼눈·오른눈 단독 가림은 변경하지 않았다.

캐시된 텍스처를 재사용하며 이동 시 UV만 갱신한다. HUD·조작창은 시야 효과 위에 표시한다. 기존 시야 가림 완화·눈 복구·내 좌석 판정·신체 경제 비활성화 처리는 유지한다.

## 실행 검증

Unity 6000.3.9f1 Windows 플레이어 0.14.4, 일반 창 1440×900. `-marble-vision-check <출력 폴더>` 실행 결과 `Validation/unity-vision-gradient-verified/runtime-validation.json`은 **passed**, 런타임 오류 없음.

정상 화면 대비 동일 지점의 평균 밝기 비율:

| 캐릭터 중심에서 거리 | 남는 밝기 |
|---|---:|
| 100 | 68.86% |
| 200 | 20.87% |
| 400 | 4.25% |
| 600 | 3.89% |

가까운 중심 표본의 정상 화면 대비 RGB 차이 합 평균은 0.00047(허용 0.005 미만), 이동 중에는 0이었다. 거리별 밝기가 감소하며 가장 먼 곳도 완전한 검정이 되지 않는지 검사했다. 중심이 약 148.7 이동한 상태에서도 추적과 그라데이션 검사가 통과했다.

기존 좌우 가림·완화·복구·HUD·다른 좌석·비활성화 검사도 통과했다. 정지·이동 양눈 상태 캡처를 직접 확인했다. 기존 검사 290개와 전체 C# 컴파일 통과, Unity 빌드 Succeeded, 경고·오류 0개.

변경 소스: `Assets/Marble/Runtime/BodyWorldLayer.cs`, `Assets/Marble/Runtime/MarbleVisionRuntimeCheck.cs`, `Assets/Marble/Editor/MarbleBuildTools.cs`.

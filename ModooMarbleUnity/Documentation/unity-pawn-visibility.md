# 보드 캐릭터 가시성

- 캐릭터를 키우고 모델 윤곽선과 대비되는 이중 테두리의 플레이어 색 받침을 표시합니다.
- 현재 차례 캐릭터는 조금 더 크고 머리 위 화살표가 있으며, 다른 캐릭터는 살짝 투명합니다.
- 캐릭터를 보드 글씨 위에 그리며, 여러 명이 같은 칸에 모이면 표시 위치를 좌우로 부드럽게 나눕니다. 실제 이동 칸과 판정은 바꾸지 않습니다.
- 시야 제한과 이동 중 카메라는 화면에 표시되는 캐릭터 위치를 따라갑니다.

화면 검증은 `Validation/unity-pawn-visibility`에서 두 명, 네 명이 모인 상황, 네 명이 다른 색 칸에 있는 상황과 시야 효과를 확인합니다. 주사위 이동 검증은 `Validation/unity-pawn-movement`에 저장합니다.

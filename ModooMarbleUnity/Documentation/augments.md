# 동시 증강 선택 — 0.10.0 소스

모든 생존 플레이어에게 동시에 3장 선택이 열리고 각자 한 장을 확정한다. 먼저 확정한 사람은 대기하고 전원 완료 시 원래 턴과 단계로 복귀한다. Steam에서는 자기 화면의 카드만 조작한다.

## 선택과 리롤

- 클릭 또는 1/2/3으로 후보 선택 → 선택 확정 / Enter.
- **카드 3장 각각 독립적으로 1회** 리롤. 한 장만 바뀌며 다른 카드의 리롤 사용권은 유지된다.
- 카드 아래의 리롤 버튼 또는 선택 후 R. 미선택 상태의 R은 사용 가능한 첫 카드에 적용한다.
- 황금 리롤은 플레이어별·페이즈별 기본 10% 확률로 등장하고 처음 리롤한 한 카드에 자동 적용된다. 그 결과만 브론즈→실버→골드→프리즘으로 한 등급 오른다. 프리즘은 상한을 유지한다.
- 황금을 사용하면 다른 카드에 남은 리롤은 일반 리롤이다. 같은 카드의 재리롤·두 번째 황금 사용·확정 후 리롤은 거부한다. 다음 일반/특수 선택 단계에서 예산을 초기화한다.
- 현재 증강 이름·설명·아이콘·효과는 계속 비어 있다. 리롤은 후보 버전과 등급을 처리한다.

기본 선택은 1·6·11·16라운드의 4회이며 호스트가 로비에서 1~8회로 설정한다. 8회 일정은 1·6·11·16·21·26·31·36라운드다. 설정을 바꾸면 준비를 초기화한다. 일반·특수를 합친 보유 상한은 플레이어당 8개다. 추가 단계는 승인된 시스템 경로 Game.RequestSpecialAugment / OnlineSession.RequestSpecialAugment로 요청하며 일반 참가자가 임의로 만들 수 없다.

## 표시

브론즈 구릿빛 #CD8B54, 실버 은빛 #C1CFDF, 골드 금빛 #F0C96A, 프리즘 무지개 색상을 사용한다. 기본 단계 등급은 공통이고 황금 리롤 적용 카드만 다른 등급이 될 수 있다. 각 플레이어 카드 위에는 보유 증강 아이콘만 표시하고 마우스를 올리면 등급·미설정 내용·소유자·일반/황금 리롤 획득 여부를 보여준다.

## 기록과 멀티

첫 후보 확정은 augment:<단계>:<좌석>:<카드>, 리롤 후에는 :v<3비트 사용 마스크>가 붙는다. 리롤 행동은 augment_reroll:<단계>:<좌석>:<카드>다. 각 카드의 사용 상태와 황금 적용 슬롯·보유 카드의 실제 등급을 상태 해시·리플레이에 포함한다. 이전 후보 확정, 다른 좌석 리롤, 잘못된 카드, 중복 사용을 거부한다.

동시 증강 요청의 과거 행동 순번은 허용하되 일반 보드 행동은 정확한 순번과 턴을 확인한다. 실제 Steam 송신자로 좌석 권한을 판정한다. 스냅샷 복구 후에도 사용한 일반·황금 리롤은 회복되지 않는다. 선택/리롤은 주사위 난수와 재화를 소비하지 않는다.

현재 온라인 호환 키는 marble-classic-online-8, 로컬 저장 형식은 v4다. 이전에 전체 후보를 리롤하던 행동 기록 또는 :r1 확정 기록은 새 규칙과 호환되지 않아 불러오기가 실패할 수 있다. 해당 기록이 없는 이전 저장은 기존 버전 판독을 유지한다.

## 검증

현재 소스 자동 검사: 증강 18·온라인 29개 포함 전체 97개 통과. 전체 런타임·에디터 소스 컴파일 통과. 새 Windows 실행 파일·화면은 미검증이며 이전 0.8.0 실행 파일에는 새 규칙이 없다. 이전 Validation/reroll-icons-*.png 및 0.8.0 빌드 보고서는 과거 UI 기록이다.

자세한 도전과제 보상·주사위 컨트롤·Steam 활성화 조건은 [기능 기록](progression-and-dice.md), 검증 결과는 Validation/progression-source-validation.json을 따른다.

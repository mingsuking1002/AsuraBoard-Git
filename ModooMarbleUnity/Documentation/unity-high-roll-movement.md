# 10·11·12 이동 확인과 포춘카드 연출 수정 — 0.17.1

## 재현

출발지에서 10은 도쿄, 11은 시드니, 12는 포츈카드에 도착한다. 주사위의 칸수 기록은 각각 10·11·12개지만 포츈카드의 이동 효과가 같은 명령의 경로에 이어 붙는다. 기존 화면은 두 이동 사이에 멈춤이 없어 12가 나온 뒤 더 많이 이동하는 것처럼 보였다.

강제 주사위 6+6, 시드 7, 출발지 0의 재현에서는 주사위 12칸으로 포츈카드 12에 도착한 다음 ‘황금열쇠 · 출발지로 이동’이 남은 20칸을 이동한다. 시드 4는 ‘앞으로 3칸’으로 상파울로 15에 도착한다. 이는 추가 주사위가 아니며, 6+6의 더블 추가 굴림과도 별개다. 재현 도구와 출력은 `Validation/HighRollProbe.cs`, `Validation/high-roll-probe.txt`에 있다.

## 변경

- 주사위 이동 중 `주사위 이동 X / N칸`을 표시한다.
- 주사위 이동 후 이벤트 이동이 이어지면 도착 칸에서 0.85초 멈추고 `주사위 12칸 완료 · 포츈카드`처럼 안내한다.
- 이어지는 이동은 당시의 카드 사유를 표시한다. 규칙 엔진의 최종 메시지가 나중에 바뀌더라도 사유를 보존한다.
- 연출 완화 설정에서는 기존처럼 추가 대기 시간을 생략한다.
- 이동 거리·카드 규칙·더블 규칙·난수 소비·온라인 판정은 변경하지 않았다. 이동 사유와 진행 칸수는 화면용 정보다.

## 검사

`MovementSelfTests`는 신체 경제 켜기/끄기 × 출발 위치 32개 × 주사위 36조합, 총 2,304가지에서 주사위로 표시된 이동 개수가 합계와 정확히 같은지 검사한다. 이벤트 이동에는 사유가 남는지도 확인한다. 기존 전체 290개 검사와 C#·셰이더·Windows 빌드를 실행했다.

`Validation/unity-high-roll-verified/runtime-validation.json`은 실제 Windows 플레이어의 결과다. 합계 10의 세 조합, 11의 두 조합, 12의 포춘카드 추가 이동·출발지 통과 등 총 9가지를 실행한다. 각 경우에서 실제 발걸음 소리 호출 수, 화면상 주사위 이동 완료 수, 최종 말 위치, 결과 주사위 면을 기록한다. 포춘카드 도착 대기와 사유 표시도 검사한다. 기존 주사위 던짐·3+5 이동·연출 완화 검사도 함께 실행한다.

- 빌드 보고서: `Validation/unity-high-roll-build-validation.json`
- 실행 보고서: `Validation/unity-high-roll-verified/runtime-validation.json`
- 배포 파일 해시: `Validation/unity-high-roll-publish.json`
- 도착 안내 캡처: `Validation/unity-high-roll-verified/07-twelve-card-arrival.png`

열린 원본 에디터 대신 검증용 프로젝트 복사본에서 빌드하고 실행한다. 실제 Steam 두 계정 간 이번 화면 연출 검사는 수행하지 않았다.

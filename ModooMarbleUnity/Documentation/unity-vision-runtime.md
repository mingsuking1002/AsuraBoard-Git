# 눈 매각 화면 수정 — 0.14.1

눈 매각으로 월드 흐림을 켜면 타일이 사라지고 선·건물이 흩어져 보이는 오류를 수정했다. 타일과 테두리가 사용하는 IMGUI 변환과 오프스크린 드로잉의 암묵적인 투영 상태가 간섭했다. 월드 드로잉 셰이더에 고정 캔버스 투영을 명시적으로 전달하고, 개별 도형의 변환은 CPU에서 한 번만 적용한다. 이동 시 확대는 완성된 월드 텍스처에 적용한다.

한쪽 눈은 블러 샘플 간격을 2.5에서 0.35로 줄였고 양쪽 눈은 9에서 2.4로 줄였다. 양쪽 눈은 더 흐리지만 보드 위치와 색은 구분할 수 있다. 환경설정의 시야 효과 완화는 이를 다시 절반으로 낮춘다. 지명·통행료·플레이어 카드·버튼은 계속 선명하게 표시한다. 매각 가격과 규칙은 바꾸지 않았다.

## 실제 실행 검증

Unity 6000.3.9f1 Windows 플레이어 0.14.1에서 `-marble-vision-check <출력 폴더>`로 실행했다. 일반 창 1440×900에서 정상 상태, 오른쪽 눈, 왼쪽 눈, 양쪽 눈, 시야 완화, 이동 중 확대의 6개 화면을 캡처했다. 테스트 모드는 신체 상태를 메모리에서 설정하며 사용자 저장 데이터는 변경하지 않는다.

- 결과: `Validation/unity-vision-verified/runtime-validation.json` — passed, 런타임 오류 없음.
- 정상 화면 대비 타일 표본 RGB 차이 합의 평균(범위 0~3): 오른쪽 0.02488, 왼쪽 0.02488, 양쪽 0.32426, 이동 확대 0.09706.
- 한쪽 눈은 0.001 초과·0.08 미만, 이동 확대는 0.15 미만으로 검사한다. 양쪽 눈은 한쪽보다 차이가 크고 0.4 미만이어야 한다. 표본에 타일 경계가 포함되어 더 강한 블러에는 더 큰 차이를 허용한다. 상단 UI 차이는 0.005 미만으로 검사한다.
- 오른쪽 눈·양쪽 눈·이동 확대 캡처를 직접 확인해 보드 형태와 건물 위치가 유지되는 것을 확인했다.
- 기존 규칙 검사 290개, Unity 빌드 통과. 빌드 경고·오류 0개.

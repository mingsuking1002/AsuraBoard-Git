# 특수능력 기능 팩 — 30종

30종의 효과를 증강 콘텐츠와 독립된 기능으로 구현했습니다. 실제 경기에 자동 발동하지 않습니다.

코드: `Assets/Marble/Core/SpecialMechanics.cs`
검사: `Assets/Marble/Core/SpecialMechanicsSelfTests.cs`

기존 `AbilityModules`의 수치/intent 처리기와 달리 이 팩은 소유한 독립 상태에서 현금·부동산·다음 이동 패널티·예약 환급·경매를 실제로 변경합니다. 두 처리기를 동시에 자동 실행하지 않습니다. 여기서 나눈 분류는 문서 편의를 위한 것이며 코드에는 증강 등급이 없습니다.

## 기능 목록

|---|---|---|
| 주사위 사기꾼 | `AdjustDice` | 본인 3턴째부터 3턴 간격, 합계 ±1 선택, 2~12 제한. 한계에서 변동이 없으면 소모하지 않음 |
| 소매치기 | `OnPassPlayer`, `Move` | 지나친 상대에게 30. 보유 현금까지만, 이동 경로 중간 칸만 통과 판정 |
| 미끄러운 바닥 | `OnLand` | 소유자가 기능을 가졌으면 방문자 추가 이동 2 반환 |
| 불법 주차 | `OnLand`, `ConsumeMoveDistance` | 방문자 다음 이동 -2, 소비 후 해제. 패널티 합산 상한 12 |

| 길막 전문가 | `ApplyRoadblock` | 본인 3턴째부터 3턴 간격, 지정 상대 다음 이동 -1 |

| 건물 도둑 | `StealBuilding` | 상대 최고 일반 건물 1개를 내 타일로 이전. 같은 종류 중복/건설 해금 제한/랜드마크 검사 |
| 부동산 폭파범 | `DisableProperty` | 현재 소유자의 턴 카운터 +2까지 통행료 전체 정지. 정지 중 재공격 보상 중복 불가 |

| 빚의 악마 | `TollQuote` | 현재 순부채 100당 +5%, 최대 +100% |

| 사이보그 건물주 | `TollQuote` | 현재 인공 부위당 +5%. 기본 인공 부위는 두 다리·폐·심장, 복구하면 제외 |

사용자가 지정하지 않은 수치는 테스트용 기본값입니다. `MechanicOptions`로 소액, 보험금, 주기, 환급율, 건설 할인, 인공 부위 마스크, 경매 조건 등을 변경할 수 있습니다. +15%, +40% 등 명시된 고정 효과와 최초 2턴 정지 등은 해당 함수에서 정의합니다.

## 호출 예

```csharp
var rules = new SpecialMechanics(
    new[] { new MechanicPlayer(), new MechanicPlayer() },
    new[] { new MechanicProperty(owner: 0), new MechanicProperty(owner: 1) });
rules.Grant(0, SpecialMechanic.UninvitedGuest);
rules.Grant(0, SpecialMechanic.DamageRefund);
long quoted = rules.TollQuote(0, 1); // 85, 조회는 소모 없음
long paid = rules.PayToll(0, 1);    // 실제 송금 85, 환급 8 예약
rules.BeginTurn(0);                // 8 환급, 턴 카운터 증가
```

`Grant`를 호출한 기능만 해당 플레이어에게 활성화됩니다. 패시브들도 전원 기본 지급하지 않습니다. 능력을 갖는 것과 공격/구매/건설 실행 권한은 별개이며, 실제 경기의 행동 선택기는 나중에 연결해야 합니다. 호출자는 활성 효과의 비용과 사용 횟수를 결정합니다.

## 상태와 경기 연결 경계

- `MechanicPlayer`와 `MechanicProperty`는 이 규칙 팩이 소유할 전용 상태입니다. 생성 시 배열은 복사하지만 요소는 소유권을 넘기는 방식이며 여러 인스턴스에서 공유하지 않습니다. 기존 Game 상태가 자동 동기화되는 구조는 아닙니다.
- 현재 위치/현금/건물/만기를 변경하는 함수와 가격을 조회하는 함수를 분리했습니다. 견적 호출만으로 일회 보너스가 소비되지 않습니다.
- 이 팩의 부채는 음수 현금의 절댓값입니다. 통행료 송금은 현재 현금 안에서 부분 지불하며, 파산·강제 차입·월급·결과 순위는 기존 Game의 책임입니다. 실제 경기 연결 시 그 결제 흐름에 맞춰 `TollQuote`와 지불 확정 훅을 연결해야 합니다.
- 모든 보드 칸은 이 테스트 상태에서는 부동산 슬롯입니다. 도시/관광지/특수 칸별 구매 가능 판정은 기존 맵 어댑터가 제공해야 합니다.
- `Move`는 경로 이동·통과 강탈·정방향 출발 통과 시 바퀴 수를 처리합니다. `OnLand`는 추가 이동량을 반환합니다. 연쇄 착지, 연쇄 상한, 출발 월급, 이동 연출은 자동 실행하지 않습니다.
- `ConsumeMoveDistance`는 다음 이동 패널티를 소비하므로 실제 주사위 이동을 확정할 때 한 번 호출합니다. 재굴림과 견적 단계에서는 호출하지 않습니다.
- 명시 호출형 이벤트이므로 `PayToll`, `OnDiceRolled`, `OnLand`, `BeginTurn` 등을 같은 사건에 중복 호출하면 중복 처리됩니다. 호스트 권한/이벤트 중복 방지/replay·save/hash 등록은 경기 연결 시 함께 작업해야 합니다.
- 건물은 기존 게임과 같은 별장/빌딩/호텔 비트이며 중복 금지와 바퀴 수 해금을 검사합니다. 랜드마크는 일반 건물 도둑/파괴/재개발 대상에서 제외합니다.
- 경매는 동시에 하나이며 진행 중 타일은 건설/훔치기/폭파/재개발이 잠깁니다. 입찰은 예치되고 낙찰금은 원래 소유자에게 지급됩니다. 최대 현금 상한으로 환급/정산이 불가능하면 상태를 유지하고 실패를 반환합니다.
- 현금 계산은 정수 버림입니다. 신체 매각 보너스 10%+20%와 통행료 수입 보너스들은 합산 후 적용하며, 이후 방문자 할인과 실제 지불액 기준 환급이 적용됩니다.
- 이 기능 팩은 독립 규칙 모듈이며 경기 연결은 별도입니다.

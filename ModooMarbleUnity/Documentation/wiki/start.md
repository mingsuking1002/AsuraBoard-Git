# 아수라판 개발 시작하기

아수라판은 2~4명이 도시를 사고 건물을 지어 통행료를 받는 Unity 파티 보드게임이다. 경제 모드에서는 빚과 신체 매각도 경기 결과에 영향을 준다. 화면 작업명은 아수라판이고 기존 Windows 실행 파일 이름은 ModooMarbleClassic.exe다.

## 첫 실행

1. 작업공간의 ModooMarbleUnity를 프로젝트 루트로 연다. 옆에는 공통 도구인 GameHarness와 게임 위키인 Game-Analysis-Wiki-OpenSource가 있다.
2. 먼저 이 위키의 ‘현재 인수인계’에서 담당과 미검증 항목을 읽는다. 게임 폴더의 HANDOFF.md가 최신 작업 상태다.
3. Windows 빌드는 Builds/Windows/ModooMarbleClassic.exe로 실행한다. 에디터에서는 ProjectSettings/ProjectVersion.txt에 적힌 Unity 6000.3.9f1로 프로젝트를 열고 Assets/Scenes/Classic.unity에서 Play를 누른다.
4. 방 만들기에서 로컬 방을 고른다. 대기 로비에서 맵과 증강 선택 횟수를 설정하고 게임을 시작한다. 빈 좌석에는 AI가 들어온다. 경기 종료 후 순위를 확인하고 로비로 돌아가 새 판을 시작할 수 있다.

## 플레이하면서 확인할 것

증강 선택 단계에서는 각 플레이어가 세 카드 중 하나를 고른다. 각 카드를 한 번씩 리롤할 수 있고, 개인에게 황금 리롤이 뜨면 첫 사용 카드에 적용된다. 기본 네 번, 최대 여덟 개다. 독립 능력 모듈은 선택 슬롯과 별도로 관리한다.

주사위 버튼을 길게 누른 뒤 놓아 이동한다. 첫 바퀴는 별장, 이후 빌딩과 호텔이 차례로 열린다. 세 건물을 갖춘 도시에서 다시 건설하면 인수 불가 랜드마크를 지을 수 있다. 돌발 카드로 추가 이동하면 주사위 걸음과 구분해 확인한다.

# 메인 메뉴와 플레이 루프

0.11.0 새 신체 경제 모드의 만기·탈락·승리 규칙은 [경제 기획 반영](body-economy/README.md)을 우선한다. 아래 0.9.0의 첫 파산 종료 설명은 이전 모드 기록이다.

0.9.0 소스 구현. 현재 배포 실행 파일은 이전 0.8.0이며 이 문서의 새 흐름은 재빌드 후 적용된다.

## 화면과 조작

1. 일반 실행은 게임판 대신 메인 메뉴를 연다. 캐릭터 커스터마이징, 환경설정, 방 만들기, 방 찾기, 나가기가 있다.
2. 커스터마이징에서 직접 제작한 로봇 4종·색상 4종을 선택한다. 로컬 이름·외형·색상은 저장된다. Steam에서는 Steam 표시 이름을 사용하며 외형·색상은 다른 참가자에게 전달된다. 능력치 변화는 없다.
3. 환경설정은 전체 음량, 효과음, 창 크기, 전체 화면 전환을 제공한다. 음량과 효과음은 저장된다.
4. 방 만들기에서 Steam 또는 로컬·AI 방을 선택하고 이름·정원 2~4명·공개 범위를 정한다. 로컬 방의 빈자리는 AI다. 생성 직후에는 반드시 대기 로비로 이동한다.
5. Steam 방 찾기는 공개 방 목록·새로고침·권한 있는 방 ID 입장을 제공한다. 친구 전용·프라이빗 방은 Steam 초대로 입장한다. 실제 초대 전송은 사용자가 오버레이에서 선택한다.
6. 로비에서 참가자·외형·색상·준비 상태를 확인한다. 호스트는 맵과 증강 횟수(기본 4, 최대 8)를 선택한다. 변경하면 온라인 준비가 초기화된다. 게스트는 준비를 누르고, 전원 준비 후 호스트가 시작한다. 온라인은 최소 2명, 로컬은 즉시 시작 가능하다.
7. 첫 파산 시 경기가 종료된다. 기존 독점·턴 제한 승리도 유지한다. 경기 결과는 승자 우선, 생존 여부, 총자산, 좌석 순서로 결정하며 매 경기 1~4위를 표시한다. 영구 랭킹·점수 서버는 없다.
8. 결과에서 같은 방 로비로 돌아가면 맵·외형·증강 설정을 유지하고 준비를 초기화한다. 다시 준비하고 시작할 수 있다. 경기 도중 게임 메뉴의 **게임 나가기 → 같은 방 로비**도 현재 경기를 끝내고 전원을 로비로 돌린다. 로비의 방 나가기는 메인 메뉴로 이동한다.

## 맵

- 월드 여행: 기존 32칸 기본 맵.
- 해안 여행: 같은 32칸 이동 구조에 해안 도시·관광지 이름을 적용한다. 도시 땅·건설 비용은 기본 대비 20% 낮고 관광지 통행료는 20% 높다.

맵은 UI 표시만 바꾸는 것이 아니라 실제 규칙 데이터에 적용하며 호스트·게스트·재현·로컬 저장에서 같은 맵을 사용한다. 로컬 저장 v3는 이름·외형·색상도 보존하며 기존 v1/v2를 읽을 수 있다.

## 구현과 검증

- `Core/PlayLoop.cs`: 화면 전이·맵 카탈로그·경기 등수.
- `Runtime/MarbleFrontEnd.cs`: 메인 메뉴·외형·설정·방 생성/검색·로비·결과.
- `Online/OnlineSession.cs`: 맵·외형 동기화·준비 초기화·전원 로비 복귀·재경기.
- 전송 호환성은 `marble-classic-online-7`. 참가자는 동일한 새 빌드를 사용해야 한다.

Unity에 포함된 Roslyn으로 전체 런타임 소스 및 에디터 소스를 컴파일했다. 순수 규칙 22, 건설 11, 증강 15, 플레이 루프 5, 온라인 27개 검사(총 80개)가 통과했다. 기존 전체 AI 경기 64회와 인메모리 온라인 경기 12회도 해당 검사에 포함된다. 맵 변경·준비 초기화·외형 전달·게스트 복귀 요청·같은 방 재시작을 확인했다.

컴퓨터 유즈·추가 승인·친구 초대·Steam 출시는 수행하지 않았다. Unity 배치 실행은 제한된 환경에서 라이선스 클라이언트 연결에 실패했으므로 새 실행 파일 빌드, 실제 화면 검증, 서로 다른 두 Steam 계정 간 테스트는 보류했다. 컴파일 검사는 실행 화면 검증을 대신하지 않는다. 결과는 `Validation/play-loop-source-validation.json`, 빌드 시도 로그는 `Validation/play-loop-build.log`를 참고한다.

에디터 실행이 가능한 환경에서는 `Build > Validate and build`로 빌드할 수 있다. 빌드 후 `-marble-loop-preview <절대경로/파일접두사>` 모드는 실제 Steam 없이 로컬 메인→로비→파산 결과→로비→재시작 화면과 JSON을 기록하도록 준비했다. 이 미리보기는 아직 실행하지 않았다.

# 아수라장 부루마블 — 경제 및 신체 매각 시스템 v1.4

> **문서 상태:** 기획 초안  
> **핵심 구조:** 자금 부족 → 마이너스 통장 활성화 → 기한 내 상환 → 신체 매각으로 자금 조달 가능 → 만기 미상환 시 탈락  
> **수치 안내:** 금액, 기한, 이자율, 확률은 모두 밸런스 테스트 전 임시 수치입니다.

---

## 1. 마이너스 통장 시스템

### 1.1 기획 의도

통행료 때문에 즉시 파산하는 상황을 방지하면서, 빚을 갚아야 한다는 긴장감은 유지합니다. 대출은 플레이를 이어가기 위한 안전망이자 공격적인 투자를 위한 전략적 선택지입니다.

### 1.2 기본 규칙

| 항목 | 규칙 |
|---|---|
| 대출 발생 | 잔액이 0G 미만이 되면 자동으로 마이너스 통장 활성화 |
| 기본 신용한도 | -1,000G |
| 상환 기한 | 최초 대출 발생 이후 3라운드 |
| 대출 이자 | 매 라운드 종료 시 미상환 금액의 5% |
| 상환 방식 | 수익 발생 시 계좌 잔액에 자동 반영 |
| 대출 중 투자 | 신용한도 내에서 토지 구매 및 건설 가능 |
| 통행료 | 신용한도를 초과하더라도 정상 지불 |
| 기한 내 완납 | 잔액이 0G 이상으로 회복되면 대출 종료 |
| **기한 내 미상환** | **게임 탈락** |

### 1.3 대출 진행 예시

이자를 제외한 단순 흐름 예시입니다.

| 라운드 | 사건 | 통장 잔액 | 상태 |
|---|---|---:|---|
| 2R | 통행료 지불 후 대출 발생 | -600G | 5R 종료 시 상환 만기 |
| 3R | 추가 투자 | -900G | 신용한도 내 투자 가능 |
| 4R | 신체 매각 | -200G | 매각 대금 700G 반영 |
| 5R | 통행료 수익 | +300G | 수익 500G로 상환 성공 |

### 1.4 예외 및 정산 규칙

1. 상환 기한은 **처음 마이너스 잔액이 발생한 시점**을 기준으로 계산합니다.
2. 추가 대출이 발생하더라도 기존 상환 기한은 연장되지 않습니다.
3. 이자는 매 라운드 종료 시 계좌 잔액을 감소시킵니다.
4. **신용한도는 토지 구매·건설 등 자발적 투자에 적용**합니다. 강제 통행료 청구에는 적용하지 않습니다.
5. 상환 기한에 도달하면 **최종 상환 기회**를 제공합니다.
6. 최종 상환 기회에는 신체 여러 부위의 긴급 매각과 자발적 부동산 매각을 허용합니다.
7. 모든 정산 후에도 잔액이 0G 미만이라면 게임에서 탈락합니다.
8. 상환을 완료했다가 이후 다시 잔액이 음수가 되면 새로운 상환 주기가 시작됩니다.

## 2. 신체 및 장기 매각 시스템

### 2.1 기획 의도

신체 매각은 단순한 파산 구제 수단이 아닙니다. **빚이 없는 플레이어도 신체를 팔아 자본을 늘리고 부동산에 공격적으로 투자**할 수 있습니다. 매각의 대가는 게임을 완전히 막는 불이익보다는 우스꽝스러운 외형·행동 변화와 가벼운 기능적 페널티로 구현합니다.

### 2.2 기본 규칙

| 항목 | 규칙 |
|---|---|
| 매각 가능 시점 | 자신의 턴 |
| 이용 조건 | 부채 유무에 관계없이 이용 가능 |
| 일반 매각 횟수 | 턴당 최대 1회 |
| 긴급 매각 | 대출 만기 정산 시 복수 부위 매각 허용 |
| 판매 대금 | 매각 즉시 통장 잔액에 추가 |
| 중복 판매 | 이미 판매한 신체는 복구 전 재판매 불가 |
| 복구 비용 | 최초 판매 가격의 150% |
| 특수효과 | 판매한 부위별 효과 전부 중첩 |
| 매각으로 인한 사망 | 없음 |
| 매각으로 인한 행동 불능 | 없음 |

- 필수 장기를 판매하면 가상의 싸구려 인공 장기로 즉시 대체됩니다.
- 신체 복구 시 해당 부위에 연결된 매각 특수효과가 해제됩니다.
- 매각은 경제적 이득을 제공하지만 외형·음향·시야·이동 연출 등에 영향을 줄 수 있습니다.

### 2.3 신체별 판매가 및 특수효과

| 부위 | 판매가(가안) | 매각 시 발생 효과 |
|---|---:|---|
| **눈 (좌·우)** | 각 400G | 한쪽 제거 시 3D 게임 월드 화면이 흐릿해짐. 양쪽 제거 시 블러가 중첩되어 맵 식별이 매우 어려워짐. UI는 정상 표시 |
| **다리 (좌·우)** | 각 700G | 주사위 이동 중 한 칸 이동할 때마다 넘어질 확률 +1%p. 양쪽 제거 시 +2%p |
| **입** | 400G | 자신의 마이크 음성이 심하게 먹먹하게 변조되어 다른 플레이어에게 전달됨 |
| **뇌 일부** | 900G | 주사위 이동 중 일정 확률로 1~2칸 역주행 |
| **신장** | 500G | 캐릭터가 가끔 오줌을 지리고 바닥에 웅덩이가 생기는 개그 연출 |
| **간** | 700G | 캐릭터 피부색이 강제로 흙색으로 고정되며 기존 피부색 스킨 설정을 무시 |
| **폐** | 600G | 마이크 음성에 기계식 호흡음이 섞임 |
| **심장** | 1,500G | 저가 인공심장에서 지속적인 '덜덜덜' 기계 소음 발생 |

**대상 정리**

- **팔:** 매각 특수효과 미정.
- **코:** 코가 없어지는 외형 전용 효과 또는 매각 대상 삭제 검토.
- **치아:** 매각 대상에서 제외.
- **위·척추·성대 등 기타 부위:** 효과 미확정, 추후 검토.

## 3. 신체 특수효과 중첩 및 게임 진행 보장

### 3.1 최상위 원칙

> **모든 신체 매각 효과는 동시에 중첩되지만, 어떤 조합에서도 플레이어가 게임을 진행할 수 있어야 합니다.**

신체 매각으로 발생하는 제한은 재미와 연출의 범위에 두며, 게임의 필수 조작·정보 확인·턴 진행 자체를 막지 않습니다.

### 3.2 중첩 규칙

| 부위 | 중첩 처리 |
|---|---|
| 눈 | 한쪽은 약한 월드 블러, 양쪽은 강한 월드 블러. 핵심 UI는 블러 제외 |
| 다리 | 각 다리의 넘어짐 확률이 가산 중첩. 넘어져도 자동 복귀 |
| 입 | 음성 먹먹함 필터 적용. 폐의 호흡음과 중첩 |
| 뇌 일부 | 이동 1회당 역주행 최대 1회. 역주행과 넘어짐 모두 발생 가능 |
| 신장 | 다른 동작 효과와 별개로 실금 연출 발생 가능 |
| 간 | 피부색 강제 변경. 다른 신체 외형 변화와 중첩 |
| 폐 | 음성에 기계 호흡음 추가. 입의 먹먹함과 중첩 |
| 심장 | 캐릭터에게서 기계 소음 발생. 입·폐 음성 변화와 중첩 |
| 코(채택 시) | 코가 사라지는 외형 변화. 다른 외형과 중첩 |

### 3.3 게임 진행 필수 보장 항목

신체를 전부 매각한 상태에서도 아래 기능을 반드시 사용할 수 있어야 합니다.

1. 주사위 굴리기와 이동 완료
2. 토지 구매 및 건물 건설
3. 통행료 지불 및 수취
4. 증강 선택 및 발동
5. 신체 추가 매각 및 복구
6. 타 플레이어와의 게임 내 상호작용
7. 자신의 위치·잔액·부채 만기·재산 등 핵심 정보 확인
8. 턴 종료와 다음 플레이어로의 진행

### 3.4 상황별 예외 처리

**양쪽 눈을 판매한 경우**

- 3D 월드 맵은 강하게 흐려집니다.
- 계좌, 증강, 주사위 결과, 위치, 도착 칸 정보 등의 UI는 선명하게 유지합니다.
- 복구 시 월드 블러를 해당 부위만큼 해제합니다.

**양쪽 다리와 뇌 일부를 판매한 경우**

- 역주행 중에도 넘어질 수 있습니다.
- 넘어지면 짧은 레그돌 연출 후 자동으로 일어나 이동을 이어갑니다.
- 역주행은 이동 1회당 최대 1회만 발동합니다.
- 연출 때문에 이동이 무한 반복되거나 턴이 종료되지 않는 상황은 금지합니다.

**입·폐·심장을 함께 판매한 경우**

- 먹먹한 음성, 기계식 호흡음, 인공심장 소음이 함께 발생합니다.
- 단, 음성이 완전히 사라지지 않도록 처리하고 기계 소음이 발화를 가리지 않게 믹싱합니다.
- 다른 플레이어는 개별 소음 크기를 조절할 수 있습니다.

### 3.5 이동 효과 처리 우선순위

1. **주사위 결과 확정:** 기본 이동 칸 수 계산
2. **뇌 역주행 판정:** 이동 경로의 역방향 구간 계산
3. **이동 및 넘어짐 판정:** 다리 효과를 이동 연출에 적용하되 자동 복귀
4. **최종 칸 도착:** 위치 확정 후 토지 구매·통행료·이벤트 처리

실금·피부색·기계 소음 등 비이동 효과는 이 절차와 독립적으로 처리할 수 있습니다.

## 4. 마이너스 통장과 신체 매각의 연계

### 4.1 정상적인 부동산 투자

신체를 팔지 않고 토지와 건물의 수익으로 자산을 늘립니다. 정상 신체를 유지하는 플레이도 경쟁력 있는 선택이어야 합니다.

### 4.2 공격적인 신체 매각 투자

빚이 없어도 눈·다리·장기 등을 매각하여 추가 투자금을 마련할 수 있습니다. 매각 대금으로 토지를 선점하거나 건물을 업그레이드하는 전략이 가능합니다.

### 4.3 부채 상환을 위한 신체 매각

마이너스 통장 상태에서 장기를 팔면 매각 대금이 즉시 잔액에 반영되어 부채가 줄어듭니다. 부채를 모두 갚으면 상환 주기가 종료되지만 신체 매각 효과는 복구 전까지 유지됩니다.

### 4.4 만기 직전 긴급 매각

상환 기한에 도달했을 때 부채가 남아 있다면 보유한 신체 여러 부위를 즉시 매각할 수 있습니다. 이때 확보한 금액과 기타 자산 처분 금액을 정산한 후에도 부채가 남아 있으면 **탈락**합니다.

## 5. 탈락 및 승리 판정

| 상황 | 처리 |
|---|---|
| 통장 잔액이 음수 | 게임 지속, 상환 기한 활성화 |
| 신용한도 초과 | 추가 투자 제한, 게임 지속 |
| 신체 전부 매각 | 게임 지속 |
| 대출 기한 내 상환 완료 | 대출 상태 종료, 정상 플레이 지속 |
| **대출 만기 미상환** | **게임 탈락** |
| 한 플레이어만 생존 | 해당 플레이어 승리 |
| 제한 라운드 종료 | 통장 잔액과 부동산 가치 등을 기준으로 최종 정산 |

**초기 점수 규칙 제안:** 신체 매각에 따른 신체 가치 차감은 최종 자산 점수에 별도로 반영하지 않습니다. 판매할 수 있는 부위의 수가 유한하므로, 신체 매각은 현금을 조기에 확보하는 대신 변형 효과를 감수하는 투자 전략으로 취급합니다.

---

## 6. 최종 핵심 규칙 요약

1. **잔액이 음수가 되어도 즉시 탈락하지 않습니다.**
2. **마이너스 통장에는 상환 기한이 존재합니다.**
3. **기한 안에 완납하지 못하면 탈락합니다.**
4. **신체는 빚이 없을 때도 매각하여 투자 자금으로 사용할 수 있습니다.**
5. **매각한 신체의 특수효과는 모두 중첩됩니다.**
6. **신체를 전부 팔더라도 게임의 필수 행동은 유지됩니다.**
7. **신체 매각 자체로 캐릭터가 사망하지 않습니다.**
8. **최종 탈락은 신체 상태가 아닌 채무 만기 미상환으로 판정합니다.**

## 7. 추후 검증이 필요한 항목

- 3라운드 상환 기한과 5% 이자의 적정성
- 신용한도를 넘는 통행료가 쌓였을 때 재기 가능한지
- 신체 판매 가격 대비 초반 부동산 투자 효율
- 심장 등 고가 장기를 첫 턴에 파는 행동이 사실상 필수 전략이 되지 않는지
- 다리 넘어짐·뇌 역주행으로 턴이 과도하게 길어지지 않는지
- 강한 월드 블러와 음성 변조에도 실제 플레이가 가능한지
- 신체 복구 가격 150%가 지나치게 비싸거나 저렴하지 않은지
- 후반부에 신체가 고갈된 플레이어에게 의미 있는 역전 수단이 남아 있는지

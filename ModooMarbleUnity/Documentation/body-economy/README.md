# 경제와 신체 매각 v1.4 반영

0.12.0에 눌러서 말하기와 항상 열림을 추가했다. [음성과 환경설정](../settings-and-voice.md)에서 현재 입력 모드와 검증 범위를 확인할 수 있다.

0.11.0 소스. 경제 설계 명세 spec-v1.4.md를 기준으로 구현했다. 배포 폴더 실행 파일은 이전 0.8.0이며 이번 변경은 아직 Windows 빌드로 생성하지 않았다.

## 플레이 흐름

일반 실행의 새 로컬 방과 Steam 방에서 신체 경제 모드를 사용한다. 메인 메뉴·대기 로비·증강·건설·주사위 컨트롤·결과·같은 방 재경기 흐름을 유지한다.

- 신체·부동산 거래 버튼 또는 B로 거래창을 연다. 자신의 턴에 신체 매각은 1회, 부동산 자발적 매각과 신체 복구는 별도로 가능하다.
- 일반 신체 매각은 부채가 없어도 가능하고 대금은 즉시 잔액에 반영된다. 더블 추가 굴림으로 매각 횟수가 초기화되지 않는다.
- 이미 판 부위는 복구 전 재판매할 수 없다. 복구비는 정해진 판매가의 150%이며 현재 현금으로 지불한다. 복구 후 같은 턴 매각 횟수는 되살아나지 않는다.
- 계좌가 음수가 되면 최초 발생 라운드 +3의 종료를 상환 만기로 기록한다. 추가 차입은 만기를 연장하지 않는다. 예: 2R 최초 차입은 5R 종료 만기.
- 토지 구매·건설·인수는 잔액 -1,000G까지 허용한다. 강제 통행료는 한도를 넘어도 전액 지불하며 수취인에게 정상 지급한다. 별도 대출 버튼이나 대출 원금 계정을 중복 적용하지 않는다.
- 음수 잔액에 라운드 종료마다 5% 이자를 붙인다. 정수 G 단위 이자는 올림한다. 0G 이상 회복하면 만기가 해제되고 이후 다시 차입하면 새 주기가 시작된다.
- 만기에는 해당 플레이어에게 최종 상환창을 연다. 신체 여러 부위와 부동산을 연속 매각할 수 있다. 랜드마크도 자발적 처분이 가능하다. 충분히 상환한 뒤 정산을 확정하면 다음 턴으로 이어진다. 미상환 상태로 확정하면 탈락한다.
- 첫 탈락만으로 경기를 끝내지 않는다. 최후의 생존자가 이기며 독점은 이 모드의 즉시 승리 조건에서 제외했다. 동시 만기자는 모두 최종 상환 기회를 받고, 전원 탈락하면 승자 없이 종료한다.
- 라운드 제한은 초기 설정 60R다. 기존 MaxTurns 안전 상한도 유지한다. 제한 종료 직전의 만기 정산을 먼저 처리하고 잔액 + 부동산 장부가로 순위를 계산한다. 별도 신체 가치 차감은 없다.

기본 1,000G 한도·3R·5%·판매가는 기획서의 임시 값이다. 60R 제한, 이자 올림, 복구의 현금 결제는 구현에서 정한 초기 세부 규칙이다. 기본 엔진 설정 EnableBodyEconomy=false의 기존 규칙도 유지하므로 과거 모드의 테스트와 저장 판독 경로를 보존한다.

## 외형·월드·이동 처리

직접 제작한 로봇의 눈·입·다리를 개별 제어하고 인공 부품을 표시한다. 기존 캐릭터 외형과 장비 색상을 기반으로 변경하며 간 효과가 활성화된 표면은 선택 색상보다 흙색을 우선한다.

0.14.2에서 좌우 방향 가림으로 변경했고, 0.14.3에서 양눈 매각 시 근거리 시야, 0.14.4에서 넓은 그라데이션을 추가했다. 왼눈 매각은 왼쪽, 오른눈 매각은 오른쪽을 가린다. 양눈이 없으면 내 캐릭터 중심 반경 약 66은 선명하고 이후 거리 600까지 점차 어두워진다(1440×900 기준 보드 좌표). 가장 먼 곳도 최대 불투명도 96%로 희미한 윤곽을 남긴다. 시야는 실제 말 이동과 카메라 확대를 따라가지만 한쪽 눈의 좌우 가림은 화면에 고정된다. 지명·통행료도 시야 효과를 받고 계좌·주사위 결과·구매창·증강창·거래창·메뉴는 유지한다. 눈 복구 시 해당 방향만 즉시 해제하며 환경설정의 시야 가림 완화는 불투명도를 절반으로 낮춘다. 이전 전체 블러와 전용 RenderTexture/GL 드로잉은 제거했다. [현재 구현과 실행 검증](../unity-vision-gradient-runtime.md).

뇌 매각의 초기 역주행 확률은 10%로 정했다. 이동 1회에 역방향 구간 1회, 길이는 1~2칸이다. 기본 주사위 이동 예산 중 일부를 역방향으로 소비한다. 역주행 자체로 월급을 지급하지 않고 한 굴림의 정방향 출발지 통과 월급은 최대 1회다. 마지막 도착 칸에서만 토지·통행료·이벤트를 처리한다.

다리 넘어짐과 뇌 역주행은 같은 경로에 함께 발생할 수 있다. 넘어짐은 0.65초의 짧은 기울어짐 후 자동 복귀하는 연출이다. 물리 관절을 사용하는 완전한 레그돌은 아직 없다. 경로·역주행 길이·넘어지는 칸을 호스트 판정과 리플레이에 기록해 멀티에서 같은 결과를 재현한다.

거래창이 열리면 뒤쪽 보드 조작과 주사위 게이지 입력을 막는다. 만기창에서는 일반 구매·굴림을 허용하지 않고 매각과 정산만 허용한다.

## 소리와 보류 항목

폐 호흡음과 심장 기계음은 각각 직접 합성한 별도 루프로 재생해 함께 중첩할 수 있다. 거래창의 기계 소음 설정에서 플레이어별 볼륨을 조절한다. 입 효과 미리듣기도 합성 신호이며 마이크 입력이 아니다.


## 저장·멀티·검증

신체 판매·복구·부동산 매각·만기 확정은 허용 행동 ID로 처리하고 실제 송신자의 좌석·현재 차례를 검사한다. 잔액·매각 부위·턴당 매각 사용·만기·라운드·정산 대기열·이동 경로를 상태 해시에 포함한다. 스냅샷도 처음부터 행동 기록을 재현한다. 온라인 호환 키는 marble-classic-online-9, 저장 형식은 v5다. 같은 새 빌드를 사용해야 한다.

Validation/VerifySource.ps1 실행 결과: 기존 규칙 22, 건설 11, 증강 18, 플레이 루프 5, 온라인 32, 진행/주사위 12, 신체 경제 21 = 총 121개 통과. 전체 런타임·에디터 C# 컴파일도 통과했다. 기존 64회 AI 경기, 온라인 12회, 새 경제 12회 전체 AI 경기를 포함한다.

새 Windows 실행 파일 빌드·Unity 셰이더 임포트/컴파일·실제 화면·실제 두 Steam 계정·사운드 청취 검증은 아직 하지 않았다. Build > Validate and build에는 새 경제 검사와 두 블러 셰이더 임포트 오류 검사를 연결했다. C# 컴파일 통과를 실제 셰이더·화면 검증으로 표현하지 않는다.

# 아수라판 — 임시 게임명과 UI 언어

사용자가 제공한 ‘아수라장 부루마블’ 경제 기획에서 출발한 임시 게임명이다. 도시 여행보다는 주사위·거래·빚과 반전을 가진 파티 보드게임이라는 성격에 맞춰, 첫 화면에 ‘굴리고, 사고, 끝까지 버텨라’라는 설명을 배치했다. 이름은 확정이나 상표 검증 결과가 아니다.

| 이전 화면 표현 | 새 화면 표현 | 게임 동작 |
|---|---|---|
| WORLD CIRCUIT | 아수라판 | 화면에 보이는 작업명만 변경 |
| 포츈카드 / 황금열쇠 | 돌발 카드 | 동일한 사건과 이동 |
| 보너스게임 | 한탕 찬스 | 기존 앞면·뒷면 선택 |
| 올림픽 | 도시 축제 | 보유 도시의 통행료 배율 |
| 월드 여행 / 해안 여행 | 세계 한 바퀴 / 해안 한 바퀴 | 기존 두 맵 |

처음 화면은 진한 보드판 배경, 손으로 그린 종이와 주사위 표시, 설명이 붙은 방 만들기·찾기 동작으로 다시 구성한다. 대기실과 경기의 상·하단도 같은 색감을 사용한다. 도움말은 현재 경제 모드와 종료 조건에 따라 실제 규칙을 설명한다.

표시 이름과 안내만 변경하고 액션 ID, 규칙, 네트워크 프로토콜, 앱 식별과 기존 `PlayerPrefs`·저장 경로는 변경하지 않았다. Unity의 내부 제품명은 기존 저장 데이터 호환 때문에 `World Circuit`으로 유지한다. 0.18.5와 0.19.0의 합성 경기·리플레이 상태 해시 비교 결과는 `Validation/identity-compat`에 남긴다.

## 검증

- Unity 6000.3.9f1 Windows 빌드와 290개 자동 검사를 통과했다. 변경 전후 경기 16판과 돌발 카드 64개 시드의 상태·리플레이 비교에서 차이는 없었다.
- 실제 실행 파일에서 메인·로비·설정, 게임 시작부터 파산과 순위 표시 및 로비 복귀, 증강 선택, 보드·시야, 주사위 10·11·12와 돌발 카드 추가 이동을 검사했다. 메인과 1280×720 로비 화면도 캡처했다.
- 두 Steam 계정과 실제 마이크는 이번에 검증하지 않았다. 현재 검증 결과는 `Validation/unity-identity-*`에 있으며 실행 파일은 `Builds/Windows/ModooMarbleClassic.exe`다.

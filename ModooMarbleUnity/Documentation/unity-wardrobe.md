# 옷장·안쪽 건설 패널·랜드마크 — 0.17.0

## 플레이어 기능

메인 메뉴 → **캐릭터 옷장**에서 변경한다. 종이 카드 UI를 유지하며 왼쪽 실제 3D 미리보기에서 회전·정면 보기를 제공한다. **저장하고 메인으로**는 프로필을 저장하고, 취소·뒤로 가기는 옷장을 열기 전 이름과 외형으로 돌아간다.

| 항목 | 선택지 |
|---|---|
| 성별 | 남성 / 여성, 모델의 masculineFeminine 블렌드셰이프 사용 |
| 피부색 | 6색, 피부 팔레트 교체 |
| 헤어 | 없음 + 10종 |
| 모자 | 없음 + 4종, 착용하면 헤어를 숨겨 겹침 방지 |
| 상의 / 바지 / 신발 | 각각 베이스 / 캐주얼 / 기사, 독립 선택 |
| 악세서리 | 없음 + 페이스 장비 / 백팩 / 기사 등 장비 / 캐주얼 장비 세트 / 기사 어깨 장비 |
| 주사위 | 기존 도전과제 해금 조건과 장착 기능 유지 |

실제 모델 부품을 조합해 로비·인게임에도 같은 외형을 사용한다. 옷은 부위별 단색 재질로 정리하고 피부·눈은 팔레트를 유지한다. 옷장을 열어 둔 상태에서 이름을 바꿀 수 있고, 외형 저장은 능력치를 변경하지 않는다. 눈·다리 매각과 인공 부품 표시도 새 모델에 연결했다.

## 자산

**FREE Starter Pack - Sidekick Modular Characters by Synty**에서 FBX 157개, PNG 팔레트 8개를 선택했다. 원본 파일 바이트의 SHA-256과 패키지 내 경로는 `asset-audit/sidekick.json`에 보존한다. `SidekickImportTools`가 정확히 이 165개만 검사한다. 패키지 에디터 스크립트·커스텀 도구는 실행하거나 가져오지 않는다.

리소스: `Assets/Marble/Resources/Downloaded/Sidekick`. 조립: `SidekickAvatar`. 의상별 추가 뼈는 공통 골격에 복제해 연결하며, 각 메시의 모든 재질 슬롯에 선택한 재질을 적용한다.

## 보드와 랜드마크

일반 28칸의 시그니처 패널은 네 라인 모두 보드 중앙을 향한 변에 배치한다. 건물 기준점도 같은 패널 중심을 사용하고, 여러 건물은 해당 변을 따라 나란히 놓인다. 모서리 네 칸의 큰 크기와 일반 칸의 동일 면적은 유지한다.

별장·빌딩·호텔을 모두 보유한 도시에서 다음 건설 기회가 오면 랜드마크 전용 창으로 비용·예상 통행료·인수 불가를 안내한다. 건설하면 기존 세 건물을 랜드마크로 전환하고 상대 인수 행동을 차단한다. 기존 엔진의 방문당 건설 제한, 원격 건설, 비용 계산을 그대로 사용한다.

## 저장과 멀티

`WardrobeCatalog`의 유효한 20비트 외형 코드가 프로필 `profile.outfit`, 게임 저장 v6 `Outfits`, 온라인 로스터·스냅샷·상태 해시에 들어간다. 이전 게임 저장 v1~5는 기본 착장으로 읽는다. 온라인 호환 버전은 `marble-classic-online-11`이며 이전 실행 파일과 혼용하지 않는다.

## 검증

- `Validation/unity-wardrobe-build-validation.json`: Unity 6000.3.9f1의 규칙·멀티·건설·보드 등 290개 검사, AI 64경기와 온라인 시뮬레이션 12경기, C#·셰이더 컴파일 및 Windows 빌드.
- `Validation/unity-wardrobe-verified/runtime-validation.json`: 실제 Windows 화면의 성별·피부·의상 변경, 모든 39개 개별 선택지 로드, 취소 복구, 외형 패킷·저장 JSON 왕복, 28개 패널 방향, 실제 랜드마크 건설과 인수 차단.
- `Validation/unity-wardrobe-vision-verified/runtime-validation.json`: 기존 눈 시야·그라데이션·이동 추적·보드 색상 검사. 건물이 패널을 덮도록 바뀌었으므로 색상 샘플은 건설하지 않은 칸에서 읽는다.
- `Validation/unity-wardrobe-dice-verified/runtime-validation.json`: 주사위 3+5 결과와 무인도 도착, 연출 완화.
- `Validation/unity-wardrobe-front-verified/runtime-validation.json`: 메인·로비·환경설정·경기·로비 복귀 및 작은 해상도.
- `Validation/unity-wardrobe-publish.json`: 검증 빌드를 기존 `Builds/Windows`에 반영한 파일 해시 비교.

검증용 프로젝트 복사본에서 빌드하고 실행해 열린 에디터의 프로젝트 잠금을 피했다. 자동 실행은 사용자 프로필 레지스트리를 변경하지 않으며, 프로필의 실제 저장·재실행 복원과 두 Steam 실계정 간 외형 표시·실제 음성은 이번 자동 검증 범위 밖이다. 온라인 외형은 가짜 백엔드 호스트/클라이언트 검사로 확인했다.

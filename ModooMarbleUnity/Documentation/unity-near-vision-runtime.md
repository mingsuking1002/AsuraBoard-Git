# 양눈 매각 근거리 시야 — 0.14.3

이 문서는 0.14.3의 검증 기록이다. 0.14.4에서는 선명한 중심을 유지하면서 바깥의 어두워지는 구간을 넓히고 먼 곳에도 희미한 윤곽을 남긴다. [현재 구현과 실행 검증](unity-vision-gradient-runtime.md).

양눈이 없으면 내 캐릭터 주변의 작은 원만 보인다. 1440×900 보드 좌표 기준 바깥 반경은 110, 완전히 보이는 안쪽 반경은 66이며 사이 구간은 부드럽게 어두워진다. 캐릭터 몸체 중심을 기준으로 하고 카메라 확대 비율을 반경에도 적용한다. 대략 주변 한두 칸을 볼 수 있다.

현재 화면에 그려지는 내 말 위치를 사용하므로 논리적인 이동 목적지로 먼저 시야가 이동하지 않는다. 상대 턴에도 내 말을 중심으로 유지한다. 판 눈이 한쪽일 때의 좌우 가림은 그대로 화면에 고정된다. 지명·통행료는 가림 아래로 옮겨 원 밖의 정보가 보이지 않도록 했다. HUD·ROLL·주사위 결과·구매·거래·설정 UI는 가림 위에 유지한다.

기존 설정과 동일하게 시야 가림 완화는 검정 불투명도를 절반으로 낮추며, 눈 복구 시 다음 프레임부터 한쪽 가림 또는 정상 시야로 돌아온다. 재생 중 매 프레임 마스크를 만들지 않고 캐시된 원형 텍스처의 UV만 이동한다. 경제 수치와 게임 규칙은 바꾸지 않았다.

## 실제 실행 검증

Unity 6000.3.9f1의 Windows 플레이어 0.14.3을 일반 창 1440×900으로 실행했다. `-marble-vision-check <출력 폴더>`는 검증 모델 메모리에서만 상태를 변경하며 사용자 저장 데이터는 바꾸지 않는다.

보고서: `Validation/unity-near-vision-verified/runtime-validation.json` — **passed**, 런타임 오류 없음.

- 정지 상태 원 안 표본의 정상 화면 대비 RGB 차이 합 평균: 0.00047(허용 0.005 미만).
- 정지 상태 원 밖 표본 밝기: 0.
- 이동·확대 중 원 안 표본 차이: 0. 원 밖 표본 밝기: 0.00291(허용 0.02 미만).
- 시야 중심이 시작 위치에서 약 146.2 이동한 상태에서도 원이 말을 따라가는 것을 확인했다.
- 좌우 한쪽 가림, HUD 유지, 완화, 복구, 다른 좌석, 신체 경제 비활성화 검사가 모두 통과했다.
- 11개 캡처 중 정지 양눈 상태와 이동 양눈 상태를 직접 확인했다.
- 기존 검사 290개 및 전체 C# 컴파일 통과. Unity 빌드 Succeeded, 경고·오류 0개.

검증 화면: `04-both-eyes.png`, `11-moving-near-vision.png`(위 보고서와 같은 폴더).

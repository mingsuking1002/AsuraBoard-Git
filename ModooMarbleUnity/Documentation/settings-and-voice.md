# 환경설정과 Steam 방 음성

0.12.0에서 눌러서 말하기와 항상 열림을 추가했다. 실제 음성 검증은 별도로 진행한다.

## 사용하는 곳

메인 메뉴 → 환경설정, 경기 중 메뉴 → 환경설정에서 같은 설정 화면을 연다. 소리, 마이크·음성, 화면·성능, 게임·편의의 네 탭이다. 저장하고 닫기로 유지하고 기본값 복원으로 초기 설정을 다시 선택할 수 있다. 설정은 게임의 경기 저장과 분리해 PlayerPrefs에 저장한다.

## 마이크와 음성

- 마이크 끄기: 캡처와 전송을 멈춘다.
- 눌러서 말하기: 기본 모드. 기본 키 V를 누르는 동안만 캡처·전송한다. V, T, 왼쪽 Ctrl 중 선택할 수 있다.
- 항상 열림: 현재 Steam 방에 들어가 있으면 말하기 키 없이 캡처한다. 입력 장치 선택·음성 활성화 임계값을 별도 제공하는 기능은 아니다.
- M 또는 설정의 내 마이크 음소거는 선택 모드보다 우선한다. 마이크 입력 크기 0%도 캡처하지 않는다.
- 다른 창 사용 시 마이크 음소거가 기본으로 켜져 있다. 사용자가 끄면 항상 열림은 방 안에서 창이 비활성화된 동안에도 유지될 수 있다.
- 로비, 경기, 결과 화면에서 현재 방 참가자끼리 음성을 주고받는다. 메인 메뉴·로컬 방에서는 마이크를 시작하지 않는다. 자동 검사·진단 실행 모드도 마이크를 시작하지 않는다.
- 방 나가기·방 이동·게임 종료는 녹음을 멈춘다. 중지 후 남은 음성은 버리고, 방 또는 경기 구분이 바뀌면 0.5초 동안 정리한 뒤 새 캡처를 시작한다.
- 로비 상단과 게임 헤더에 마이크 상태를 표시한다. 이 표시는 소프트웨어의 활성 상태이며 장치·네트워크 실측 결과를 보증하지 않는다.

Steam의 기본 마이크 입력과 Unity의 기본 재생 출력을 사용한다. 현재 Steam Voice API 연결에는 앱 자체 장치 선택 목록이 없어서 동작하지 않는 장치 선택 UI를 넣지 않았다.

## 음량과 참가자별 조절

전체 음량, 효과음, 음성 수신, 마이크 입력 크기, 인공 장기 소음을 분리했다. 효과음 음소거와 상대 음성 음소거도 따로 적용한다. 다른 창 사용 시 전체 소리를 줄이는 옵션이 있다.

마이크·음성 탭의 참가자별 음량 또는 신체 거래창의 기계 소음 설정에서 각 참가자의 수신 음량·음소거와 장기 소음을 조절한다. 온라인은 Steam ID 기준으로 저장해 좌석이 바뀌어도 같은 사람의 설정을 사용한다. 내 마이크를 스피커로 되돌려 재생하지 않는다. 합성 소리 미리듣기는 실제 마이크 테스트가 아니다.

입을 매각했다면 송신 쪽에서 먼저 먹먹한 필터를 적용한 뒤 재압축해 전송한다. 폐의 기계 호흡음은 수신자의 개인별 소음 설정을 적용해 음성에 섞는다. 별도 호흡·심장 루프도 유지하며 발화가 감지되면 해당 참가자의 장기 루프 음량을 줄인다.

## 화면과 편의

| 설정 | 적용 |
|---|---|
| 해상도 | 1280×720, 1440×900, 1920×1080 |
| 화면 모드 | 창, 테두리 없는 전체 화면, 전체 화면 |
| FPS 제한 | 30, 60, 120, 144, 무제한 |
| 수직 동기화 | 켜기/끄기. 실제 FPS는 주사율의 영향도 받음 |
| 절전 | 30 FPS와 VSync 해제를 우선 적용. 끄면 저장한 FPS/VSync 선택 복원 |
| 연출 완화 | 주사위 회전·말 점프·대기 흔들림을 줄이고 이동 연출을 단축. 판정은 동일 |
| 월드 흐림 완화 | 눈 매각 시 화면 블러 강도를 절반으로 완화. 핵심 UI는 계속 선명 |
| 턴 알림음 | 내 차례·증강 선택 단계 알림 |
| 초대 자동 입장 거부 | 게임이 Steam 초대를 받아 자동으로 입장하는 처리를 차단. Steam 자체 알림을 차단하는 것은 아님 |

초대 자동 입장 거부를 켜도 방 찾기·방 ID를 통한 직접 입장은 가능하다. 현재 게임에 실제 배경음악 트랙, FPS 시점 카메라, HDR·필름 그레인 조절이 없어 그 항목들은 추가하지 않았다.

## 참고 게임 조사

### Gamble With Your Friends

참고 설치본 Assembly-CSharp.dll의 선택 CIL을 조사했다. 실행 검증은 하지 않았다. 파일 SHA-256은 f2147868930f1fc9df3489ef89339759f7eeb8a92c270bec094a4ece6dd2935b, MVID는 d531044a-de62-4d57-85e9-3914d8e9adc0다.

- DisplaySettingsApplier.Apply: 해상도·화면 모드·주사율을 Screen.SetResolution으로 적용.
- FramerateSettingsApplier.Apply: FPS를 Application.targetFrameRate로 적용. VSync는 QualitySettings.vSyncCount에 연결.
- SoundSettings: 전체·음악·SFX·VOIP 구분.
- InputSettingsApplier: inputvolume을 FMODMicrophoneInput.InputGain에 적용. Dissonance의 말하기 모드와 IsMuted 제어.
- EscapeMenuVoiceList 및 PlayerVoiceVolumePersistence: 참가자별 음량 저장·복원.

REA 근거: ev_cc6648c6c7797b8dca77d7d4e497bac968042e306e2464872459b45d135982e0. 원본의 VoiceActivation은 음성 활성화 방식이며 우리 항상 열림과 같은 동작으로 단정하지 않았다. Dissonance·FMOD 코드나 음원을 프로젝트에 복사하지 않았다.

### MECCHA CHAMELEON

참고 설치본의 Manifest_UFSFiles_Win64.txt에서 설정 자산 경로를 확인했다. WBP_ConfigSound, WBP_ConfigGraphic, WBP_ConfigGameGeneral, WBP_ComboBox_ScreenMode, WBP_SettingSliderFPS, WBP_PerformaiceMode, 음성 입력/출력 장치, VoiceChatUserSettings와 VoiceChatLists가 포함된다. 경로 존재만으로 실제 동작·기본값까지 확인했다고 표현하지 않았다.

### 리그 오브 레전드

[Riot 공식 음성 안내](https://support.riotgames.com/en-us/league-of-legends/performance/league-voice-chat-troubleshooting)에서 눌러서 말하기와 입력 모드·장치 설정 설명을 확인했다. 우리 게임은 말하기 키와 입력/수신 음량을 채택하고, Riot의 파티 음성 서비스나 장치 선택 구현을 사용하지 않는다.

### Stacklands

[개발팀의 2023-10-16 v1.4.1.20 공지](https://store.steampowered.com/news/posts/?enddate=1697466252&feed=steam_community_announcements)의 Stacklands 항목에서 음악·SFX 음량 슬라이더 추가를 확인했다. 이는 과거 패치 근거이며 현재 전체 설정 도감을 조사한 결과는 아니다. 이번 환경에서 Stacklands 설치본은 확인되지 않아 실행·배포 코드 조사는 하지 않았다.

## 전송 구조와 확인 범위

음성은 규칙 데이터와 별도인 Steam Networking Messages 채널 18을 사용한다. 방 ID·경기 구분 Guid·현재 실제 송신자 ID·멤버 목록을 검사한다. 방 밖의 송신자, 자기 자신의 패킷, 이전 방/경기 패킷은 재생하지 않는다. 로비는 별도 빈 Guid를 사용한다.

Steam Voice 압축 데이터를 로컬에서 PCM으로 해제한 뒤 입 효과를 먼저 적용하고 최대 2,400샘플 단위로 Deflate 압축한다. 수신 시 샘플 수와 복원 길이를 제한해 무제한 압축 해제를 하지 않는다. 송신·수신 버퍼를 제한하고 오래된 대기 음성을 버린다. 음성은 파일·경기 리플레이·진행 저장에 기록하지 않는다. 마이크 증폭은 패킷에 제한된 수치로 담고 수신 재생에 적용한다.

검증 결과는 Validation/voice-settings-source-validation.json을 따른다. 순수 규칙 22·건설 11·증강 18·플레이 루프 5·온라인 32·진행 12·신체 경제 21·음성/설정 20 = 141개 검사와 전체 런타임·에디터 C# 컴파일이 통과했다. 음성 검사는 가짜 캡처 백엔드와 합성 샘플만 사용했다.

실제 마이크 권한·장치 신호·두 Steam 계정 간 통화·통신 지연·실제 볼륨·설정 화면과 저장 복원·새 Windows 빌드는 미검증이다. 이 작업에서 Unity 실행·컴퓨터 유즈·마이크 접근·실제 음성 전송은 하지 않았다. 현재 배포 실행 파일은 이전 0.8.0이며 새 소스 빌드 후 사용할 수 있다. 온라인 호환 키는 marble-classic-online-10이다.

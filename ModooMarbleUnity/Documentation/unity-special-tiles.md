# 특수 타일 표시

- 포춘카드: 흰 바탕과 무채색으로 그린 겹친 물음표 카드. 별도 색 띠는 표시하지 않음.
- 보너스게임: 연한 금색 바탕과 별이 든 금색 보상 동전.
- 관광지: 해당 보드 라인의 띠색으로 타일 전체를 채우고 야자수·모래섬 표시. 구입한 관광지는 소유자의 색 받침을 가진 입체 야자수로 표시.

네 방향의 라인 색과 기존 타일 글씨, 보드 셀, 판정 및 이동 규칙을 유지합니다. 포춘카드와 관광지에는 별도의 입체 색 띠를 그리지 않습니다. 아이콘은 코드로 그립니다.

Unity에서 기본 보드의 포춘카드 4칸, 보너스게임 1칸, 관광지 5칸과 소유한 관광지, 네 방향 라인 색, 입체 모형 정렬을 점검합니다. 화면 확인과 결과는 `Validation/unity-tile-colors`에 저장합니다.

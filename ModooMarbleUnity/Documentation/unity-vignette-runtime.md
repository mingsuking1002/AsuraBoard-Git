# 좌우 눈 매각 시야 가림 — 0.14.2

이 문서는 0.14.2의 검증 기록이다. 0.14.3부터 양눈이 없으면 캐릭터 주변만 보이고 원 밖의 지명도 가린다. [현재 동작과 실행 검증](unity-near-vision-runtime.md).

전체 가우시안 블러를 제거하고 화면에 고정된 검은 비네트로 교체했다. 왼눈을 팔면 왼쪽, 오른눈을 팔면 오른쪽을 가린다. 두 눈을 모두 팔면 월드 전체가 가려진다. 없어진 눈의 방향별 상태를 확인하므로 단순히 없어진 눈 개수로 처리하지 않는다.

## 렌더와 상태 처리

보드·말을 정상 렌더한 다음 카메라 확대 행렬을 해제하고 1440×900 캔버스에 가림을 그린다. 그 위에 지명·통행료·HUD·주사위 조작·거래창과 설정을 그린다. 보드가 확대돼도 가림 방향은 고정된다. 512×320 RGBA 마스크를 상태별로 한 번 생성해 재사용한다.

내 로컬 좌석의 눈 상태만 적용한다. 매각·복구 후 다음 프레임부터 반영하고, 신체 경제를 끈 방에서는 가리지 않는다. 환경설정의 ‘눈 매각 시 시야 가림 완화’는 가림 불투명도를 50%로 낮춘다. 기존 ComfortBlur 저장 키를 유지해 사용자의 설정이 보존된다. 경제 수치와 규칙은 변경하지 않았다.

전체 블러용 RenderTexture·사용자 GL 드로잉·두 셰이더는 제거했다. 시야 효과로 보드의 도형 변환이 달라지지 않는다.

## 실행 검증

Unity 6000.3.9f1, Windows 플레이어 0.14.2, 일반 창 1440×900에서 `-marble-vision-check <출력 폴더>`로 실행했다. 상태는 테스트 모델 메모리에서 변경하며 사용자 저장 데이터는 변경하지 않는다.

`Validation/unity-vignette-verified/runtime-validation.json`: **passed**, 런타임 오류 없음.

# 바닥에 던져 구르는 주사위 — 0.18.1

두 주사위가 공중에서 날아와 서로 다른 시간에 착지하고, 작아지는 두 번의 반동과 바닥 위 구름을 거쳐 멈춘다. 굴림은 약 1.55초이며 결과 확인 후 말이 이동한다. 게임 규칙이나 난수에는 영향을 주지 않는 화면 연출이다.

각 프레임의 주사위 방향에 따라 둥근 주사위 메시의 아래쪽 접점을 계산한다. 공중에서는 접점에서 높이만큼 올리고, 닿을 때는 바닥보다 아래로 내려가지 않도록 놓는다. 그림자도 같은 바닥 위치를 따라가고 높이에 따라 크기와 진하기가 바뀐다. 착지마다 작은 선 효과와 줄어드는 충돌음이 재생된다. 두 주사위의 세 번 착지, 총 여섯 번을 각각 처리한다.

최종 결과 면을 주사위 윗면에 놓고 카메라를 위쪽으로 조정해 눈이 보이게 했다. 연출 완화 설정에서는 이전처럼 굴림을 생략한다. 선택된 주사위 외형, 증강·신체 상태, 기존 이동 경로는 유지한다.

## 검증

- `Validation/unity-dice-grounded-build.json`: Unity 6000.3.9f1 빌드와 기존 규칙·온라인·이동·건설 등 290개 검사.
- `Validation/unity-dice-grounded-final/runtime-validation.json`: 실제 Windows 플레이어에서 공중 비행·바닥 접점·주사위별 착지 6회 순서·3+5 결과 윗면·이동 대기·연출 완화·10/11/12 이동 9가지 검사.
- `Validation/unity-dice-grounded-final/02-flight.png`, `03-bounce.png`, `03b-ground-roll.png`, `04-result.png`: 실제 화면 캡처.
- `Validation/unity-dice-grounded-publish.json`: 검증 빌드와 배포 폴더의 파일별 해시.

충돌음은 기존 설정으로 조절하는 합성 효과음이다. 자동 검사는 발생 시점을 확인하며, 실제 오디오 장치에서 청취한 검사는 포함하지 않는다.
